# JavaScript Assignments and Capstone Project

## Overview
This repository contains six JavaScript practical assignments and an Interactive Product Inventory & Analytics Dashboard capstone project.

## Assignments
1. Variables, Data Types, and Console Operations
2. Operators, Expressions, and Input Handling
3. Conditional Logic Implementation
4. Loop Control Structures
5. Function Architecture and Scope
6. Arrays, Objects, and Core Methods

## Capstone Project
**Project Title:** Interactive Product Inventory & Analytics Dashboard

Features:
- Product input using `prompt()`
- Product validation and category badges
- Inventory search using loops
- Inventory value calculations
- Tax and discount calculations
- Product filtering and formatted reports using `forEach()`, `filter()`, and `map()`

## Technologies
- JavaScript
- HTML
- Node.js for running JavaScript assignments

## How to Run
1. Download or clone this repository.
2. Run the `.js` assignments using Node.js in the terminal.
3. Open `assignment2.html` in a web browser for the bill calculator.
4. Open `Product_Inventory_Dashboard/index.html` in a browser to run the capstone project.

Open the browser Developer Tools with `F12` and select **Console** to view output.
